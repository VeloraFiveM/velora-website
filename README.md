# Velora public website

React and TypeScript frontend for https://playvelora.xyz. Backend and secrets are maintained separately. Applications, tickets and management features are under development.

Node 24 and pnpm 11.25.0: pnpm install, pnpm dev, pnpm lint, pnpm typecheck, pnpm test, pnpm build.

GitHub Actions validates and deploys main to GitHub Pages. The custom domain is playvelora.xyz.
